# Solo-Setup

> An opinionated workflow stack for solo founders / vibe coders using Claude.ai (chat) + Claude Code (terminal) + Linear + GitHub.

**Status:** v0.1 in active development (target ship: end of May / early June 2026)

This repository is the deliverable for an emerging meta-project that generalizes a battle-tested solo-founder workflow into a public reference. The v0.1 user-facing docs are not yet drafted; current contents are pre-v0.1 design history (`docs/design/`) and decisions (`docs/decisions/`).

If you're an early visitor, the most useful files right now are:
- [`docs/design/01_LOAD_FIRST_project_overview.md`](docs/design/01_LOAD_FIRST_project_overview.md) — orientation
- [`docs/design/02_source_workflow_distilled.md`](docs/design/02_source_workflow_distilled.md) — the source workflow patterns we generalize from
- [`docs/design/astro_playbook_v2.md`](docs/design/astro_playbook_v2.md) — second case-study workflow
- [`docs/decisions/`](docs/decisions/) — append-only decision log

The user-facing v0.1 documentation will land in `docs/00_quickstart.md` through `docs/13_*.md` over weeks 2–4.
